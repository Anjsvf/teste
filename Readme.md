#  Lista de Funcionários

 projeto  que exibe uma lista de funcionários com funcionalidades de busca e expansão de detalhes. Consumindo dados de uma API  simulada para mostrar informações como foto, nome, cargo, data de admissão e telefone dos colaboradores.

## 🚀 Funcionalidades
- **Listagem de Funcionários:** Exibe uma tabela com os dados dos colaboradores como foto, nome , cargo, data de admissão e telefone.
- **Busca Inteligente:** Permite filtrar os funcionários por nome, cargo ou telefone.
- **Detalhes Expansíveis:** Clique no ícone de seta para expandir e ver mais detalhes sobre um funcionário.
- **Formatação:**  Data e número de Telefone formatados no Frontend.
- **Responsividade:** A tabela é totalmente responsiva e se adapta a diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas
- **React com vite** 
- **TypeScript** 
- **CSS** 
- **API (dados da API simulada)** 


## 🚀 Como Executar o Projeto
passos abaixo para configurar e executar o projeto localmente:

1. Clone o repositório:
   ```bash
   git clone https://github.com/Anjsvf/teste

   cd teste/Frontend
 
   ```

2. Instale as dependências:
   ```bash
   npm install
   # ou
   yarn install
   ```

3. Configure a API:
   - Certifique-se de que a API está rodando e acessível.
   - Atualize o arquivo `src/Services/api.ts` com o endereço correto da API.

4. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   # ou se preferir
   npm start
   # ou
   yarn start
   ```

5. Acesse o projeto:
   Abra o navegador e acesse: [http://localhost:3000](http://localhost:3000)
